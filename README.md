# Virtual Shopping Simulation

A React application that simulates a virtual shopping experience, allowing users to enter a starting budget, browse products by categories, and make purchases.

The app starts with a budget entry on the home page, guides the user to the product catalog, and manages the checkout and purchase process.

## Features

- Starting budget input with validation
- Category-based product filtering
- Diverse product listings and images
- Real-time remaining budget tracking after purchases
- Smooth page navigation with React Router DOM
- Modern and clean user interface

## Technologies Used

- React
- Vite
- React Router DOM
- JavaScript
- CSS
